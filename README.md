# Visualización para la Analítica de Datos – Fase 2

Este proyecto corresponde al componente práctico del curso **Visualización para la Analítica de Datos**.  
El objetivo es aplicar técnicas de análisis y visualización para explorar un dataset de restaurantes en Colombia, integrando gráficos estadísticos y mapas geoespaciales en un dashboard interactivo con **Dash** y **Folium**.

---

## 📊 Contenido del proyecto

- **Dataset:** `Anexo 1 - dataset fase 2.xlsx` con información de restaurantes (categoría, calificación, precio promedio, reseñas, coordenadas).
- **Shapefile:** `COLOMBIA.shp` y archivos asociados para la representación geográfica de departamentos.
- **Scripts principales:**
  - `Visualizacion_de_Datos.py` → Dashboard interactivo con Dash.


---

## ⚙️ Tecnologías utilizadas

- **Python 3.13**
- **Dash** (para el dashboard interactivo)
- **Plotly Express** (gráficos estadísticos y coropletas)
- **Folium** (mapas geoespaciales)
- **GeoPandas** (manejo de shapefiles y operaciones espaciales)
- **Pandas** (procesamiento de datos)
